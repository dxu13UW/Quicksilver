# shared/
- `samples/`: real item texts copied from the game with Ctrl+C, one `.txt` per item, named by type (e.g. `rare_helmet_01.txt`, `unique_tabula.txt`, `currency_divine.txt`). These are test fixtures for the parser. Collect a variety: currency, uniques, rares, gems, maps, corrupted, influenced, 6-links.
